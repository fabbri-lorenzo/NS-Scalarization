# Scalarization of Neutron Stars
Numerical analysis of the ODEs describing a Neutron Star in the model of **Early Modified Gravity** ( [Braglia et al.](https://arxiv.org/pdf/2011.12934)) using **Runge-Kutta 4th Order Method** with Python. In this setting, a threshold for the phenomenon of spontaneous scalarization ([Doneva et al.](https://arxiv.org/pdf/2211.01766)) is determined.

This is the code implemented for my Master's thesis in Theoretical Physics at the University of Bologna.
